# amplitude_1e-2_initial_rho

Variação de amplitude 1e-2: 200 amostras, WLSQR, três famílias, estratégia initial_rho.

Configuração: `config.yaml`. Execute `bash run.sh` nesta pasta ou de qualquer diretório.
Saídas numéricas: `Result/run_*/`, logs em `logs/`, temporários em `tmp/`, todos nesta pasta.
Nenhuma campanha foi executada durante a preparação. Consulte `../AUDIT.md`.
